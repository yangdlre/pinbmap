# pinbmap

good food, good coffee.

- `index.html` : 앱 본체 (카카오 지도)
- `netlify/functions/kplace.mjs` : 평점·리뷰·블로그 수·유가·충전기 상태를 가져오는 작은 서버 함수 (Netlify에서만 동작)
- `netlify/functions/sync.mjs` : 여행방(일정표·할일·경비)과 내 설정 코드(기기끼리 설정)를 맞추는 저장 함수 (Netlify Blobs 사용)
- `package.json` : 위 저장 함수가 쓰는 라이브러리 목록 (Netlify가 배포할 때 자동 설치)
- `netlify.toml` : Netlify 설정 (빌드 없음, 함수 폴더 지정)

GitHub Pages에서는 함수가 돌지 않아 거리 기준으로만 동작합니다.

## v0.45
- 새 메뉴 틀: 아래 탭 4개 **찾기 · 내 여행 · 내 장소 · 지출**, 위 줄 **여행 이름▾ · 👥 함께 · ⚙️ 설정**. 창은 아래 탭 위까지만 열리고 '닫기'를 누르면 찾기(지도)로.
  - 내 여행: 한눈에 · 일정 · 준비·할일 · 사진·기록 / 내 장소: 가고 싶은 곳 · 다녀온 곳 / 지출: 여행 경비 · 가계부 (여행 기간이면 경비, 아니면 가계부가 먼저)
- 찾기: 검색 조건은 요약 한 줄("맛집 · 음식점 · 1km · 추천 · TOP 5") → 누르면 아래에서 조건 창. '이 지역 검색'은 지도 아래 가운데 큰 버튼.
- 지도 위 버튼은 '레이어'(위성 · 다녀온 곳 · 지역 · 가고 싶은 곳 지도에) + '목록'만. 설정의 '지도 위 버튼 배치'는 감춤.
- 한눈에: 여행 전엔 할일·일정 짜기, 여행 중엔 **다음 일정 + 길안내**가 맨 위, 여행 뒤엔 사진·기록.
- 여행 선택 창(위 줄 여행 이름): 📨 공유받은 여행 · 지금 여행 · 지난 여행(🗺 흔적 · 열기 · 삭제) · 새 여행. 공유받은 여행 개수와 남은 할일 개수 배지.
- 다녀온 곳 목록(내 장소): 지금 여행 ✅ + 보관함 여행을 한데 모아, 누르면 갔던 날·메모·사진.
- 찾기: 종류 칩 한 줄(식사 · 커피 · 관광·자연 · 주유·충전, 관광일 땐 제주 전체) — 누르면 바로 검색. 지도 아래 '지도 · 오늘 · 모아보기'(오늘 = 오늘 동선, 모아보기 = 가고 싶은 곳 + 다녀온 곳) + 이 지역 검색.
- 장소 카드: '일정에 담기'를 맨 위 큰 버튼으로, 아래에 '이런 곳도 함께'(지금 검색 결과의 다른 곳 3곳).
- 여행 선택 창의 지난 여행을 '나의 책장'(대표 사진 표지 카드)으로. 색감은 짙은 초록 + 크림.
- 화면 글자 '보류' → '가고 싶은 곳'. 자료 이름·저장 방식·서버 함수는 v0.44 그대로라 기존 자료를 그대로 불러옴.
