# pinbmap

good food, good coffee.

- `index.html` : 앱 본체 (카카오 지도)
- `netlify/functions/kplace.mjs` : 평점·리뷰·블로그 수·유가·충전기 상태를 가져오는 작은 서버 함수 (Netlify에서만 동작)
- `netlify/functions/score.mjs` : ② 종합 점수 (공식 검색 API·공공데이터·우리 앱 기록, 키는 환경변수)
- `netlify/functions/sync.mjs` : 여행방(일정표·할일·경비)과 내 설정 코드(기기끼리 설정)를 맞추는 저장 함수 (Netlify Blobs 사용)
- `netlify/functions/board.mjs` : ❓ 도움말 페이지의 🎉 축제(관광공사 TourAPI, TOUR_KEY)·📢 공지(마스터만 쓰기)·✉️ 건의(저장 + 앱이 Netlify Forms로 메일 알림)
- `package.json` : 위 저장 함수가 쓰는 라이브러리 목록 (Netlify가 배포할 때 자동 설치)
- `netlify.toml` : Netlify 설정 (빌드 없음, 함수 폴더 지정)

GitHub Pages에서는 함수가 돌지 않아 거리 기준으로만 동작합니다.

- 🔁 재방문: 이미 일정에 있는 곳은 상세창 '＋ 한 번 더 담기 (재방문)'으로 하나 더 담아 다른 날 넣기.
- 📋 카드 문자: 하나카드 카톡 알림톡처럼 '가맹점명 :'·'거래시간 :' 항목형 인식, 카톡 '대화 내용 내보내기' 텍스트를 통째로 붙여도 건마다 나눔.
- 🔘 지도 위 버튼 배치(⚙️ 설정): 일정·할일·경비·가계부·보류·위성·다녀온 곳·목록·지역을 윗줄/둘째 줄 왼쪽/오른쪽/숨김으로, ↑로 순서. ⚙️은 늘 윗줄 끝. 계정으로 기기끼리 맞춤.
