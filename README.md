# pinbmap

good food, good coffee.

- `index.html` : 앱 본체 (카카오 지도)
- `netlify/functions/kplace.mjs` : 평점·리뷰·블로그 수·유가·충전기 상태를 가져오는 작은 서버 함수 (Netlify에서만 동작)
- `netlify/functions/sync.mjs` : 여행방(일정표·할일·경비)과 내 설정 코드(기기끼리 설정)를 맞추는 저장 함수 (Netlify Blobs 사용)
- `package.json` : 위 저장 함수가 쓰는 라이브러리 목록 (Netlify가 배포할 때 자동 설치)
- `netlify.toml` : Netlify 설정 (빌드 없음, 함수 폴더 지정)

GitHub Pages에서는 함수가 돌지 않아 거리 기준으로만 동작합니다.

## v0.41

- 📍 주소로 장소 찾기: 장소 찾기 칸에 주소(예: 제주시 서해안로 468-2)를 넣으면 카카오 주소 검색으로 위치를 찾아 목록 맨 위에 📍 주소 줄. 이름을 붙여 📅 담기·🚗 TMAP. 카카오에 없는 새 가게도 위치 있는 장소로 일정에 들어감.
- 📅 일정 '+ 직접'에 주소 칸(선택): 넣으면 위치가 붙어 지도·길안내 가능.
- 📒 가계부(💳 경비 화면 위 📒 가계부 · 주소 ?book): 월별 합계, 카테고리별 막대(월 예산 선, 넘으면 빨강), 날짜별 목록·수정·삭제·되돌리기, 이 달 엑셀(CSV). 카테고리·아이콘·예산 편집. 계정으로 내 기기끼리만 맞춤(친구에게 안 보임).
  - 여행 N빵 경비는 내가 낸 돈이 아니라 '내 몫'만 가계부에 더해 봄(켜고 끔).
  - 💳 경비에 👥 같이(N빵) / 👤 나만(가계부) 스위치: 나만으로 쓰면 카테고리를 골라 내 가계부로만 기록.
  - 📋 카드 문자로 넣기: 승인 문자를 붙여넣으면 금액·가게·날짜·시간·카드 자동 인식(여러 통, 취소는 마이너스, 이미 넣은 건 자동으로 빼둠), 카테고리 추측.
- 홈 화면 앱 정보(manifest·아이콘): 설치하면 아이콘 길게 눌러 📒 가계부·📅 일정 바로가기, 문자 → 공유 → 핀볼지도로 카드 문자 바로 보내기(share target).
- 서버: 계정에 book(가계부) 추가 — 바뀐 게 없으면 다시 안 보냄/안 받음.
