# pinbmap

good food, good coffee.

- `index.html` : 앱 본체 (카카오 지도)
- `netlify/functions/kplace.mjs` : 평점·리뷰·블로그 수·유가·충전기 상태를 가져오는 작은 서버 함수 (Netlify에서만 동작)
- `netlify/functions/sync.mjs` : 여행방(일정표·할일·경비)과 내 설정 코드(기기끼리 설정)를 맞추는 저장 함수 (Netlify Blobs 사용)
- `package.json` : 위 저장 함수가 쓰는 라이브러리 목록 (Netlify가 배포할 때 자동 설치)
- `netlify.toml` : Netlify 설정 (빌드 없음, 함수 폴더 지정)

GitHub Pages에서는 함수가 돌지 않아 거리 기준으로만 동작합니다.


## v0.36 게임 개편

기존 Netlify 프로젝트에 같은 방식으로 업로드하세요. 서버 함수와 지도·검색·일정·동기화 기능은 그대로 포함되어 있습니다.

- 설정 → 지도 카드 동작 → 게임 B 또는 C 선택.
- 카드를 화면 맨 아래까지 당겼다 놓으면 게임이 열립니다.
- B 받아치기 바: 바를 잡거나 아래 조작판을 밀어 바 위치를 정합니다. 공을 좌우로 밀어 바 위 공 위치를 정한 뒤, 공을 아래로 당겼다가 놓으면 반대 방향으로 발사됩니다. 조금만 건드리거나 위로 되돌리면 발사되지 않습니다.
- C 핀볼: 오른쪽 공을 아래로 당겨 발사합니다. 충분히 당기면 상단 곡선 통로를 거쳐 테이블로 들어옵니다. 약하게 쏴서 통로로 돌아온 공은 차감되지 않습니다. 화면 아래 양쪽 버튼은 두 손가락으로 동시에 누를 수 있습니다. 발사 버튼도 사용할 수 있습니다.
- 공이 빠지면 다시 준비 상태로 돌아갑니다. 자동 재발사는 없습니다.
- 설정 및 게임 안 ⚙에서 속도 40~150% 조절. 기본 70%, 게임 A/B/C별로 기억합니다. 바 이동과 터치 입력은 즉시 반응합니다.
- '편하게 놀기' 기본 활성화: 공 무제한. 해제하면 공 3개. 핀볼은 테이블 진입 직후 게임 시간 8초 동안 한 번 공 보호.
- 일시정지, 화면 전환 시 자동 정지, 조용한 효과음 선택, 클리어·잭팟 이후 계속하기.
- PC: 바는 ← → 또는 A/D. 핀볼 플리퍼는 ← → 또는 A/D, 진행 중 Space는 양쪽 플리퍼. 준비 상태 Space는 발사, P 일시정지, Escape 일시정지/복귀.
- 테이블은 고정 비율로 확대/축소되므로 폴드 접기·펼치기나 PC 화면에서도 중앙 간격 비율이 같습니다.

검증: 게임 상태·발사·공 차감·보호·동시 플리퍼·일시정지·화면 비율·렌더링 호출을 코드 수준에서 검증했습니다. 이 작업 환경의 브라우저 실행 검증은 제공되지 않아, 실제 휴대폰에서 조작 감각과 화면 표시를 확인해 주세요.
