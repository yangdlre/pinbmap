# pinbmap

good food, good coffee.

- `index.html` : 앱 본체 (카카오 지도)
- `netlify/functions/kplace.mjs` : 평점·리뷰·블로그 수·유가·충전기 상태를 가져오는 작은 서버 함수 (Netlify에서만 동작)
- `netlify/functions/sync.mjs` : 여행방(일정표·할일·경비)과 내 설정 코드(기기끼리 설정)를 맞추는 저장 함수 (Netlify Blobs 사용)
- `package.json` : 위 저장 함수가 쓰는 라이브러리 목록 (Netlify가 배포할 때 자동 설치)
- `netlify.toml` : Netlify 설정 (빌드 없음, 함수 폴더 지정)

GitHub Pages에서는 함수가 돌지 않아 거리 기준으로만 동작합니다.


## v0.37 핀볼 (지도 위 방식 유지 + 시스템 개선)

- 게임은 v0.35처럼 지도 위에서 실제 카드를 깨는 방식. 📅 일정 버튼 5번(× 내구성) = 7777 잭팟.
- 게임 속도 40~150%(기본 70%, A·B·C 따로): 시간 배율(슬로모션)이라 느려도 공은 천장까지 감.
- B·C는 공이 빠지면 대기 → 공을 잡고 아래로 당겼다 놓으면 당긴 반대 방향으로 발사(조준선 표시). PC는 스페이스.
- C 치수는 공 크기 기준(플리퍼 공 3.6개, 쉬는 상태 끝 사이 틈 공 1.6개). 레일은 벽~플리퍼 축까지 빈틈없이.
- 볼 세이브 8초, 편하게 놀기(공 무제한, 기본), 일시정지(화면 나가면 자동)·게임 안 속도 조절, 클리어·잭팟 뒤 계속하기, 효과음(선택), 끼임 방지.


## v0.38

- 📍 장소 찾기(지역 이동 칸): 음식점만이 아니라 공항·주차장·터미널·숙소 등 모든 장소를 가까운 순 15곳까지 목록으로. 줄마다 📅 일정에 담기·🚗 TMAP. 맨 아래 '네이버 지도 / TMAP'으로 같은 검색어를 그 앱 목록에서 열기.

- 핀볼 속도 10~150%.
